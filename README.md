# Demo-Att

A simple student attendance management UI built with HTML, CSS, and vanilla JavaScript.

## Features

- Add student records with name, roll number, and attendance status
- Persist student data in browser local storage
- Search student list by name or roll number
- View attendance status and dashboard summary

## Deployment

This project can be deployed as a static website using GitHub Pages.

## How to run locally

1. Open `index.html` in a browser, or start a local server:

```bash
python -m http.server 8000
```

2. Open `http://localhost:8000`

## CI

GitHub Actions validates HTML and CSS on every push to `main`.
